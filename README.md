# Ретро-рамка

Программа для Windows, которая оформляет фото, видео и музыку в окна в стиле Windows 95, 98 и 2000.

## Скачать

Последняя собранная версия лежит в разделе [Releases](../../releases/tag/latest): файл `RetroFrame.exe`.

Устанавливать ничего не нужно, программа запускается на Windows 10 и 11.

## Библиотека иконок

Кнопка «Библиотека...» в группе «Иконка» открывает все иконки сразу: встроенные и из подключённых папок и архивов. В них ищутся файлы `.ico` и `.png`, включая вложенные папки.

- ZIP-архивы программа читает сама.
- Для 7z и RAR нужна программа [7-Zip](https://7-zip.org): установленная или файл `7za.exe` рядом с `RetroFrame.exe`.
- Кнопка «Своя...» берёт иконку из картинки, `.ico` или прямо из `.exe` и `.dll`: если в файле их несколько, откроется список.

## Сборка

Программа написана на C++ с Win32 API, без фреймворков. Сборка запускается автоматически на GitHub при каждом изменении в ветке `main` и выкладывается в Releases. Изменения в ветках `claude/...` тоже собираются, но в Releases не попадают.

Собрать локально можно в Visual Studio 2022 с компонентом «Разработка классических приложений на C++» или из командной строки:

```
cmake -S . -B build -A x64
cmake --build build --config Release
```

Проверки ядра (ZIP, библиотека иконок, снимки окон) запускаются на Linux:

```
tests/run_tests.sh
```
