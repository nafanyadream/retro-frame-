# Ретро-рамка

Программа для Windows, которая оформляет фото, видео и музыку в окна в стиле Windows 95, 98 и 2000.

## Скачать

Последняя собранная версия лежит в разделе [Releases](../../releases/tag/latest):

- `RetroFrame-with-ffmpeg.zip` — программа вместе с ffmpeg для видео и музыки, достаточно распаковать в одну папку;
- `RetroFrame.exe` — только программа (фото работают и так, для видео и музыки нужен `ffmpeg.exe` рядом).

Устанавливать ничего не нужно, программа запускается на Windows 10 и 11.

## Видео

Вкладка «Видео» вставляет ролик (MP4, MOV, AVI, MKV, WebM или анимированный GIF) в окно-плеер: ползунок перемотки едет вместе с роликом, время в строке состояния идёт посекундно.

- Результат: MP4 со звуком или GIF. «Только окно» — в файле один плеер; «На фоне» — плеер посередине кадра 1:1, 4:5 (лента Instagram), 9:16 (Reels, TikTok, Shorts) или 16:9 с фоном-цветом или картинкой.
- Частоту кадров MP4 можно оставить как в ролике или выбрать 15–60 кадров в секунду.
- Можно сохранить ролик целиком или фрагмент.
- «Проиграть» показывает ролик со звуком; флажок «Звук» его выключает.
- Можно открыть или перетащить сразу несколько роликов: стрелки на панели переключают их, «Сохранить все...» сохраняет все в папку.
- Для видео нужна программа [ffmpeg](https://ffmpeg.org/download.html), она уже лежит в архиве `RetroFrame-with-ffmpeg.zip`. Если скачивать отдельно — проще всего взять `ffmpeg-release-essentials.zip` с сайта [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), достать из папки `bin` файл `ffmpeg.exe` и положить рядом с `RetroFrame.exe`. Фото работают и без неё.
- Сборки со словом `shared` в названии не работают поодиночке: им нужны ещё DLL-файлы из той же папки `bin`. Если видео не открывается, программа покажет, что ответил ffmpeg.

## Музыка

Вкладка «Музыка» превращает песню (MP3, FLAC, WAV, OGG, M4A) в видео с ретро-плеером, в котором полоска и время идут вместе с треком, диск крутится, а шкала громкости прыгает под музыку.

- Исполнитель, название и обложка берутся из тегов файла, их можно поправить.
- «Только окно» — в файле один плеер без фона, размер зависит от масштаба рамки (по умолчанию 3x).
- «На фоне» — плеер посередине кадра 1:1, 4:5, 9:16 или 16:9 с фоном-цветом или картинкой.
- Вместо диска можно включить эквалайзер в стиле Winamp: столбики прыгают по частотам песни.
- Текст песни: если рядом с песней лежит файл `.lrc` с тем же именем (или его выбрать кнопкой), под плеером бежит строка с текущей строчкой.
- Результат: MP4 со звуком (15–60 кадров в секунду, по умолчанию 25) либо PNG-кадр на выбранной секунде.
- У фрагмента звук плавно нарастает и затухает.
- Песню можно прослушать прямо в программе; несколько песен открываются очередью и сохраняются все сразу.
- Тоже нужен `ffmpeg.exe` рядом с программой.

## Эффекты

Кнопка «Эффекты...» включает по отдельности:

- анимацию открытия окна в начале видео и музыки;
- курсор мыши (стрелка, песочные часы, стрелка с часиками) у крестика, в центре, справа внизу или на кнопке окна-ошибки;
- окна-ошибки поверх окна: одно, каскад или каскад, появляющийся по очереди, со своим текстом, значком и кнопками;
- экран старого монитора (ЭЛТ) или VHS-кассеты.

Эффекты действуют на фото, видео и музыку.

## Наборы оформления

Кнопка «Наборы...» сохраняет текущее оформление окна (стиль, цвета, иконку, заголовок, тип окна, панели) под своим именем. Сохранённые наборы включаются одним щелчком в меню «Наборы». Для начала есть три готовых набора.

## Библиотека иконок

Кнопка «Библиотека...» в группе «Иконка» открывает все иконки сразу: встроенные и из подключённых папок и архивов. В них ищутся файлы `.ico` и `.png`, включая вложенные папки.

- ZIP-архивы программа читает сама.
- Для 7z и RAR нужна программа [7-Zip](https://7-zip.org): установленная или файл `7za.exe` рядом с `RetroFrame.exe`.
- Кнопка «Своя...» берёт иконку из картинки, `.ico` или прямо из `.exe` и `.dll`: если в файле их несколько, откроется список.

## Сборка

Программа написана на C++ с Win32 API, без фреймворков. Сборка запускается автоматически на GitHub при каждом изменении в ветке `main` и выкладывается в Releases. Изменения в ветках `claude/...` тоже собираются, но в Releases не попадают.

Собрать локально можно в Visual Studio 2022 с компонентом «Разработка классических приложений на C++» или из командной строки:

```
cmake -S . -B build -A x64
cmake --build build --config Release
```

Проверки ядра (ZIP, библиотека иконок, видео и музыка через ffmpeg, снимки окон) запускаются на Linux:

```
tests/run_tests.sh
```
