# Ретро-рамка

Программа для Windows, которая оформляет фото, видео и музыку в окна в стиле Windows 95, 98 и 2000.

## Скачать

Последняя собранная версия лежит в разделе [Releases](../../releases/tag/latest): файл `RetroFrame.exe`.

Для работы нужен .NET Framework 4.8, он уже есть в Windows 10 и 11.

## Сборка

Сборка запускается автоматически на GitHub при каждом изменении в ветке `main`.

Собрать локально можно в Visual Studio 2022 с компонентом «Разработка классических приложений .NET»: открыть `src/RetroFrame/RetroFrame.csproj`, выбрать конфигурацию Release и собрать проект.
